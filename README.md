## What it does

`main.py` writes exactly one letter to `/output/entry.txt`:

- `A` = coffee
- `B` = tea

This entry chooses **A (coffee)** — the more vivid, stronger,
more unmistakable hot drink.

## Run

```sh
python3 main.py
```

Output: `/output/entry.txt` containing exactly `A`, no newline,
no extra content, UTF-8, 1 byte.

Deterministic, no network, no randomness.
